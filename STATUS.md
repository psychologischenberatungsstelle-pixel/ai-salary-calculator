## 🚀 NÄCHSTE SCHRITTE

**Um das Projekt zu starten, brauchst du:**

### 1️⃣ Node.js installieren
```
Download: https://nodejs.org (Version 20.x LTS)
```

### 2️⃣ Dependencies installieren
```powershell
cd "c:\Users\Sasch\Ki Project Sascha 1.0"
npm install
```

### 3️⃣ Development Server starten
```powershell
npm run dev
```
→ Öffne `http://localhost:3000` im Browser

### 4️⃣ Auf Vercel deployen (kostenlos)
```powershell
# GitHub Repo erstellen, dann:
git init
git add .
git commit -m "Initial commit"
git remote add origin DEINE-REPO-URL
git push -u origin main

# Auf vercel.com: New Project → GitHub Repo auswählen → Deploy
```
